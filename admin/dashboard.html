How Delivery Works

Normal: Order date + category production days = earliest normal date.
Urgent: If enabled, customer can request tomorrow delivery and the category urgent fee is added.
Multiple items: final production date should use the longest production time in the order.
Admin: manually verify artwork, payment, production and delivery before moving the order through its statuses.
